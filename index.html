1. 概述

check.py 是「CSV Check」教学工具的检查脚本。它读取一张学生成绩表格（CSV 文件）， 校验表头（第一行）的列名是否满足要求——默认要求包含 id、name、score 三列。

核心特性 本工具只检查列名，不检查分数数值，也不修改任何数据。它是一次只读的检查，输入文件不会被改动。

检查结束后，脚本会打印一份简短报告，并通过退出码告诉调用方结果：通过为 0、不通过为 1、读取出错为 2。

2. 功能说明

  • 读取 CSV 文件，解析表头（第一行）与数据行。
  • 校验表头是否包含必填列（默认 id name score，可用 --require 自定义）。
  • 输出报告：文件路径、数据行数、列名清单、缺失列、最终结论 PASS / FAIL。
  • 输入无法读取时（空文件、非 UTF-8 编码、路径不存在等），输出 ERROR 提示并给出下一步建议。

命令行参数

参数 说明
file（位置参数，必填） 要检查的 CSV 文件路径。
--require 列名...（可选） 自定义必填列名，默认值为 id name score。可传入一列或多列。

用法示例

# 默认检查 id、name、score 三列
py check.py samples/students.csv

# 只要求 id 和 name 两列
py check.py samples/missing-name.csv --require id name

7.2 底层校验规则

check.py 调用的 inspect_csv 会依次校验以下规则，任一不满足即抛出 CsvCheckError：

  1. 文件必须有表头（首行非空）。
  2. 表头列名不能为空（不能是纯空白字符）。
  3. 表头列名不能重复。
  4. 每一行的字段数量必须与表头一致。
  5. 文件必须能以 UTF-8 编码读取（兼容带 BOM 的 UTF-8）。
关于退出码 check.py 通过 sys.exit() 返回 0 / 1 / 2 三种退出码，便于在自动化脚本中判断结果（详见 5.5）。

1. Overview

check.py is the checking script of the "CSV Check" teaching tool. It reads a student grade table (a CSV file) and validates whether the column names in the header (the first row) meet the requirements — by default it requires the three columns id, name and score.

Core behaviour The tool checks column names only — it does not check score values and never modifies any data. It is a read-only check; the input file is left untouched.

After the check, the script prints a short report and signals the result to the caller via an exit code: 0 for pass, 1 for fail, and 2 for a read error.

2. Features

  • Reads a CSV file and parses the header (first row) and the data rows.
  • Validates that the header contains the required columns (default id name score; customisable via --require).
  • Prints a report: file path, row count, column list, missing columns, and the final verdict PASS / FAIL.
  • When the input cannot be read (empty file, non-UTF-8 encoding, missing path, etc.), prints an ERROR hint with a suggested next step.

Command-line arguments

Argument Description
file (positional, required) Path to the CSV file to check.
--require COLUMN... (optional) Custom required column names. Defaults to id name score. Accepts one or more columns.

Usage examples

# Check the default id, name, score columns
py check.py samples/students.csv

# Only require the id and name columns
py check.py samples/missing-name.csv --require id name

6. Troubleshooting

Symptom Cause Solution
The command produces no output at all and the prompt returns immediately python is a Microsoft Store stub that exits silently Replace python with py in the command.
'py' is not recognized as an internal or external command The Python Launcher is not installed, or is not on PATH Install Python 3 and tick "Add to PATH", or run Python via its full path.
ERROR: File has no header. The file is empty (0 bytes) and has no header row Use a non-empty CSV file that has a header (e.g. students.csv).
ERROR: Cannot read a UTF-8 CSV file: ... The file is not UTF-8 encoded, or the path is wrong Re-save the file as UTF-8 in Notepad, or double-check the path spelling.
Result: FAIL with Missing columns: name A required column is absent from the header Add the missing column name to the header.
ERROR: Header names must be unique. The header contains duplicate column names Rename the duplicate columns so that every name is distinct.
ERROR: Header names must not be blank. A column name in the header is empty Give the empty column a valid name.
ERROR: Row N has M fields; expected ... A row has a different number of fields than the header (e.g. an extra comma) Check the row for a missing or extra comma so its field count matches the header.
Path contains spaces or non-ASCII characters Always wrap the path in double quotes when changing directory, e.g. cd "C:\Users\ASUS\Desktop\28.10\writing-practice", otherwise spaces or special characters can break path parsing.

7.2 Low-level validation rules

The inspect_csv function called by check.py validates the following rules in order; any failure raises CsvCheckError:

  1. The file must have a header (the first row must be non-empty).
  2. Header column names must not be blank (no whitespace-only names).
  3. Header column names must be unique.
  4. Every row must have the same number of fields as the header.
  5. The file must be readable as UTF-8 (a UTF-8 BOM is also accepted).
About exit codes check.py returns exit codes 0 / 1 / 2 via sys.exit() so that automation scripts can act on the result (see 5.5).
