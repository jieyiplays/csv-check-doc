1. 概述

check.py 是「CSV Check」教学工具的检查脚本。它读取一张学生成绩表格（CSV 文件）， 校验表头（第一行）的列名是否满足要求——默认要求包含 id、name、score 三列。

核心特性 本工具只检查列名，不检查分数数值，也不修改任何数据。它是一次只读的检查，输入文件不会被改动。

检查结束后，脚本会打印一份简短报告，并通过退出码告诉调用方结果：通过为 0、不通过为 1、读取出错为 2。

2. 功能说明

  • 读取 CSV 文件，解析表头（第一行）与数据行。
  • 校验表头是否包含必填列（默认 id name score，可用 --require 自定义）。
  • 输出报告：文件路径、数据行数、列名清单、缺失列、最终结论 PASS / FAIL。
  • 输入无法读取时（空文件、非 UTF-8 编码、路径不存在等），输出 ERROR 提示并给出下一步建议。

命令行参数

参数 说明
file（位置参数，必填） 要检查的 CSV 文件路径。
--require 列名...（可选） 自定义必填列名，默认值为 id name score。可传入一列或多列。

用法示例

# 默认检查 id、name、score 三列
py check.py samples/students.csv

# 只要求 id 和 name 两列
py check.py samples/missing-name.csv --require id name

3. 依赖

3.1 运行环境

  • Python 3：仅使用标准库，无需安装任何第三方包。

3.2 用到的标准库

模块用途
argparse解析命令行参数（文件路径、--require）。
sys读取退出码、退出程序。

check.py 依赖同目录下的 csvcheck 包（文件夹），主要成员：

成员说明

CsvCheckError自定义异常，输入无法作为表格读取时抛出。
__version__版本号，当前为 "1.0.0"。
版本提示 脚本启动时第一行会打印 CSV Check 1.0.0，该版本号即来自 csvcheck.__version__。

4. 操作步骤

  1. 打开终端：按 Win 键，输入「终端」或「PowerShell」并回车。
  2. 进入项目目录（路径含中文与空格，引号不可省略）： 
    cd "C:\Users\ASUS\Desktop\28.10\学生实践包\01_写作练习"
  3. 运行检查： 
    py check.py samples/students.csv
Windows 用户提示 部分 Windows 系统中，python 命令会静默退出、无任何输出；遇到这种情况请改用 py 命令运行（详见故障排除）。

5. 预期输出

5.1 正常通过（PASS）

输入 samples/students.csv（三列齐全）：

退出码 0 · PASS
CSV Check 1.0.0
File: samples/students.csv
Data rows: 3
Columns: id, name, score
Missing columns: none
Result: PASS
PASS checks column names, not score values.

5.2 缺少列（FAIL）

输入 samples/missing-name.csv（缺 name 列）：

退出码 1 · FAIL
CSV Check 1.0.0
File: samples/missing-name.csv
Data rows: 1
Columns: id, score
Missing columns: name
Result: FAIL
PASS checks column names, not score values.

5.3 空文件（ERROR）

输入 samples/empty.csv（0 字节，无表头）：

退出码 2 · ERROR
CSV Check 1.0.0
ERROR: File has no header.
Next step: use a readable UTF-8 file with a header row.

5.4 文件不存在（ERROR）

输入一个不存在的路径时：

退出码 2 · ERROR
CSV Check 1.0.0
ERROR: Cannot read a UTF-8 CSV file: [Errno 2] No such file or directory: 'samples\nonexistent.csv'
Next step: use a readable UTF-8 file with a header row.

5.5 退出码含义

退出码含义
0检查通过（PASS），表头包含全部必填列。
1检查未通过（FAIL），存在缺失列。
2输入读取失败（ERROR），抛出了 CsvCheckError。

6. 故障排除

现象 原因 解决办法
运行后没有任何输出，光标直接回到提示符 python 是微软商店的空壳程序，静默退出 把命令里的 python 换成 py。
提示 'py' 不是内部或外部命令 未安装 Python Launcher，或 PATH 未包含它 安装 Python 3 并勾选「Add to PATH」，或改用 Python 的完整路径运行。
ERROR: File has no header. 文件为空（0 字节），没有表头行 换一个带表头的非空 CSV 文件（如 students.csv）。
ERROR: Cannot read a UTF-8 CSV file: ... 文件编码不是 UTF-8，或路径写错 用记事本把文件另存为「UTF-8」编码；或检查路径拼写是否正确。
Result: FAIL 且 Missing columns: name 表头缺少某一必填列 在表头补充对应列名（如 name）。
ERROR: Header names must be unique. 表头有重复的列名 把重复的列名改成互不相同的名字。
ERROR: Header names must not be blank. 表头中某个列名为空 为空的列名补上有效名字。
ERROR: Row N has M fields; expected ... 某一行字段数量与表头不一致（如多了逗号） 检查该行是否有多余或缺失的逗号，使其字段数与表头一致。
路径含中文或空格 进入目录时务必用双引号把路径整体包起来，例如 cd "C:\Users\ASUS\Desktop\28.10\学生实践包\01_写作练习"，否则会因空格或中文导致路径解析错误。

7.2 底层校验规则

check.py 调用的 inspect_csv 会依次校验以下规则，任一不满足即抛出 CsvCheckError：

  1. 文件必须有表头（首行非空）。
  2. 表头列名不能为空（不能是纯空白字符）。
  3. 表头列名不能重复。
  4. 每一行的字段数量必须与表头一致。
  5. 文件必须能以 UTF-8 编码读取（兼容带 BOM 的 UTF-8）。
关于退出码 check.py 通过 sys.exit() 返回 0 / 1 / 2 三种退出码，便于在自动化脚本中判断结果（详见 5.5）。
